4 · Backend Medusa — resumen del arranque

Se resolvió una cadena de bloqueos de entorno (Windows + pnpm + Medusa 2.17):

  • Docker Desktop no arrancaba: faltaba la variable ProgramData al lanzarlo desde automatización → relanzado con la variable.
  • Medusa no corre con Node 24 → se instaló Node 22 LTS portátil solo para el backend.
  • Faltaban ts-node y tsconfig-paths (los usa el CLI de Medusa) → instalados.
  • pnpm aislado no exponía módulos internos de Medusa → node-linker=hoisted en .npmrc.
  • tsconfig del backend forzaba moduleResolution: Node clásico → se heredó NodeNext del base (resuelve @medusajs/framework/*).
  • Se compiló packages/shared a dist y se quitó el alias a fuente (errores de rootDir).
  • Providers de pago PayPal/Square: exportaban mal la clase → envueltos en ModuleProvider(...); su API (métodos/firmas) cambió en 2.17 y quedan marcados para portar.

Resultado: medusa db:migrate ✅, medusa build ✅ "completed successfully".
