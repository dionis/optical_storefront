# Modelos 3D de Gafas (Format .glb)

Coloque aquí los archivos `.glb` optimizados generados por el pipeline en `/services/optimizer/`.
Los nombres de los archivos deben coincidir con los atributos `data-sku` definidos en `index.html`:

- `classic-aviator.glb` (Aviador clásico)
- `retro-wayfarer.glb` (Wayfarer retro)
- `vintage-round.glb` (Redondas vintage)
- `bold-square.glb` (Cuadradas modernas)

## Fallback Procedimental
Si un modelo `.glb` no se encuentra en esta carpeta, el visualizador web generará automáticamente un modelo de gafas 3D de alta fidelidad procedimental con lentes reflectantes y montura morada metálica para fines de prueba rápida de tracking facial y depuración.
